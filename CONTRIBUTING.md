# Contributing

Use synthetic names and invented fixtures. Do not copy a personal account directory, a conversation export, employer documents or production credentials into the repository.

1. Install with `npm ci` and build with `npm run build`.
2. Run `npm test` and `npm run audit:public`.
3. Keep rendering, native permissions and provider calls separate. Preserve cancellation and the previous answer on recoverable failure.
4. For UI changes, check the real interface with keyboard navigation, large text, empty context and the smallest supported window.
5. For audio or sharing changes, state the exact OS, capture mode and receiving view used. A unit test is not a live audio or capture test.

Do not add unverified claims of invisibility, detection evasion, universal compatibility or guaranteed latency. Keep scope and evidence in the pull request.
