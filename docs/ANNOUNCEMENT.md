# Suggested announcement

I’m building Cue: a small, translucent assistant for conversations and practice. Add your own context, then choose your ChatGPT account, an OpenAI or Claude API key, or download local AI inside the app. No Terminal required.

The Mac preview is open source. Local mode has no per-answer API bill and runs inference on your device after setup. Cloud models remain the stronger option for difficult questions.

Apple silicon only for now. It’s a preview, not yet Apple notarized. Windows support is being evaluated. Use assistance where participants or the rules permit it.

[Source and Mac preview](https://github.com/balabommablock-cpu/cue)

## Facts for replies

Local choices: Qwen3 1.7B, 4B and 8B, with Whisper Base for English listening. Recommended starting configuration: Apple silicon Mac, macOS 14.2+, 16 GB RAM, Balanced model. See [limits and downloads](LOCAL_AI.md). No universal invisibility or answer-speed guarantee is made.
